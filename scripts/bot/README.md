# Telegram-бот (тупой сборщик)

Ловит твои сообщения в Telegram и складывает их в сегодняшний daily-лог
(`01_raw/health/<дата>.md`, секция `## входящие`). Никакого LLM и анализа — только сбор.
Анализ («это я или биология», синтез недели) делает агент в Claude Code, читая собранное.

Бесплатно: Telegram Bot API бесплатен, бот крутится локально на маке (long-polling, без сервера).

## Настройка

1. В Telegram напиши [@BotFather](https://t.me/BotFather) → `/newbot` → получи **токен**.
2. Впиши токен в `.env`: `TELEGRAM_BOT_TOKEN=...` (оставь `TELEGRAM_CHAT_ID` пустым).
3. Запусти: `pnpm bot`.
4. Напиши своему боту любое сообщение — он ответит твоим `chat_id`.
5. Впиши его в `.env`: `TELEGRAM_CHAT_ID=...`, перезапусти `pnpm bot`. Теперь бот принимает
   только из твоего чата и пишет в лог.

## Использование

- Просто пиши, как прошёл день: «настроение 4, энергия 3, силовая 50, кофе утром, виделась с подругой».
- `/today` — показать сегодняшний лог.
- Всё падает строками `- HH:MM <текст>` в `## входящие`. Структурирую при следующем разговоре/синтезе.

## Держать всегда включённым (опц.)

LaunchAgent, чтобы бот стартовал с маком и перезапускался:

```bash
cp scripts/bot/com.health-harness.bot.plist.example ~/Library/LaunchAgents/com.health-harness.bot.plist
# заменить ПУТЬ при необходимости, затем:
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.health-harness.bot.plist
```

Логи бота — `.bot/bot.log`. Токен под `.gitignore`/`deny`-read, наружу не уходит.
