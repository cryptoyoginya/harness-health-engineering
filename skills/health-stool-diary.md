# Стул-дневник: Бристольская шкала, не диагноз

Бот складывает фото с подписью «стул» в `/01_raw/health/photos/stool/` (локально, в git не уходит).
Агент описывает их **по канону** (Bristol Stool Scale) и связывает с питанием/гидратацией/стрессом.
Ценность — в паттерне за дни, не в одном кадре.

> ⚠️ **Не диагностика.** Агент описывает форму/цвет/частоту и сопоставляет с логами — не ставит
> диагнозов (СРК, целиакия, инфекция и т.п.). Red-flags ниже → **к врачу**, без интерпретаций.

## Bristol Stool Scale — тип (форма ↔ транзит)

| Тип | Вид | Что обычно отражает |
|---|---|---|
| 1 | твёрдые отдельные комки («орешки») | запор, медленный транзит, мало воды/клетчатки |
| 2 | колбасковидный, бугристый | склонность к запору |
| 3 | колбасковидный с трещинами | **норма** |
| 4 | гладкий мягкий «колбаска/змейка» | **норма (идеал)** |
| 5 | мягкие комки с чёткими краями | склонность к послаблению, мало клетчатки |
| 6 | рыхлый, рваные края, кашицей | быстрый транзит, ближе к диарее |
| 7 | водянистый, без твёрдого | диарея, очень быстрый транзит |

Цель-ориентир — **3–4**. 1–2 = суше/медленнее (вода, клетчатка, магний), 6–7 = быстрее
(триггер-еда, стресс, инфекция — последнее не диагностируем).

## Цвет (описательно)

| Цвет | Частая бытовая причина | Действие |
|---|---|---|
| коричневый | норма (желчь + билирубин) | — |
| зелёный | быстрый транзит, много зелени/железа | наблюдать |
| жёлтый, жирный, плавает, зловонный | возможна мальабсорция жиров | стойко → вопрос врачу |
| очень светлый/глинистый | мало желчи (печень/желчные пути) | стойко → **к врачу** |
| **чёрный, дёгтеобразный** | возможна кровь из верхних отделов ЖКТ | **к врачу безотлагательно** |
| **красный (кровь)** | геморрой/трещина ИЛИ серьёзнее | **к врачу** (не интерпретируем сами) |

## Что связывать (гипотезы, INFERENCE)

- тип 1–2 ↔ мало воды/клетчатки, путешествия, опиоиды/железо, малоподвижность;
- тип 6–7 ↔ триггер-еда (жирное, кофе, алкоголь, FODMAP, сорбит/подсластители), стресс (gut-brain), магний;
- частота и регулярность ↔ режим питания, клетчатка, сон/стресс;
- зловонность/жир ↔ жирная еда, мальабсорция (как вопрос, не диагноз).

## Red-flags → сразу к врачу (назвать и направить, не «анализировать»)

- чёрный дёгтеобразный или **видимая кровь**;
- стойкое изменение ритма/формы дольше ~2 недель без причины;
- сильная боль, лихорадка, непреднамеренная потеря веса, ночные позывы;
- светлый/глинистый стул + тёмная моча/желтушность.

> Острая сильная боль/кровотечение — неотложно, а не запись в дневник.

## Связь с killer-петлёй

Стул — быстрый, честный прокси пищеварения. Устойчивый паттерн («тип 6 каждый раз после молочки/кофе»)
→ оформить **n-of-1** (убрать одну переменную на 2 недели, критерий: доля типов 3–4 ↑). См.
[[n-of-1-experiments]] и [[health-attribution]]. North-star напоминает: цель — самочувствие, а не
«идеальный стул» (см. [[health-life-review]]).

## Форма вывода

```
FACT: 4 фото за неделю [source: /01_raw/health/photos/stool/].
FACT: пн/ср — тип 4, пт/сб — тип 6, цвет коричневый.
FACT: пт/сб в логах — кофе натощак + молочка, мало воды [source: /01_raw/health/2026-06-12.md].
INFERENCE (low): послабление в пт/сб совпало с молочкой+кофе; данных мало.
→ Если повторится — n-of-1: «2 недели без молочки», критерий: доля типов 3–4 ↑.
RED-FLAG: нет.
UNKNOWN: 4 точки мало; нужно 2–3 недели для ритма.
```
