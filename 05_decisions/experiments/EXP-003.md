# EXP-003: витамин D3+K5 утром каждый день

> n-of-1 trial (single-subject). В бэклоге — дизайн фиксируется ДО старта по рубрике в
> [`/METHODOLOGY.md`](../../METHODOLOGY.md) §2a–2b. Поднять из бэклога: `/exp extend 3`.

DECISION: добавить D3+K5 утром каждый день на 3 недели и измерить эффект.

- **Гипотеза:** дефицит D3 снижает энергию/настроение → добавка утром поднимает их.
- **Что меняю:** ровно ОДНА переменная — D3+K5 утром. Остальное держу неизменным. Один активный за раз.
- **Baseline (до):** ⏳ медиана за стабилизационную неделю (НЕ со «дна» — иначе спутаем с регрессией к среднему).
- **Срок:** 3 недели.
- **Первичная метрика (одна):** ⏳ уточнить — напр. настроение avg (1–5). Вторичные только наблюдаем.
- **Критерий успеха (пред-регистрация):** ⏳ порог по первичной метрике, выше обычного недельного разброса.
- **Washout / реверс:** по умолчанию ДА (D3 выводится медленно — washout длиннее; отметить как ограничение).
