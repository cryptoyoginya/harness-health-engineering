# EXP-004: магний вечером каждый день

> n-of-1 trial (single-subject). В бэклоге — дизайн фиксируется ДО старта по рубрике в
> [`/METHODOLOGY.md`](../../METHODOLOGY.md) §2a–2b. Поднять из бэклога: `/exp extend 4`.

DECISION: добавить магний вечером каждый день на 3 недели и измерить эффект на сон.

- **Гипотеза:** магний вечером улучшает качество сна → выше recovery наутро.
- **Что меняю:** ровно ОДНА переменная — магний вечером. Остальное держу неизменным. Один активный за раз.
- **Baseline (до):** ⏳ медиана за стабилизационную неделю (НЕ со «дна» — иначе спутаем с регрессией к среднему).
- **Срок:** 3 недели.
- **Первичная метрика (одна):** ⏳ уточнить — напр. эффективность сна по Whoop, avg. Вторичные только наблюдаем.
- **Критерий успеха (пред-регистрация):** ⏳ порог по первичной метрике, выше обычного недельного разброса.
- **Washout / реверс:** по умолчанию ДА — убрать магний в конце, проверить откат сна.
