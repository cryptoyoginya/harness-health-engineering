# EXP-002: убрать добавленный сахар после 18:00

> n-of-1 trial (single-subject). Дизайн фиксируется ДО данных — см. рубрику вердикта в
> [`/METHODOLOGY.md`](../../METHODOLOGY.md) §2a–2b. Единственный активный эксперимент.

DECISION: убрать добавленный сахар после 18:00 на 3 недели и измерить эффект на сон.

- **Гипотеза:** добавленный сахар вечером ухудшает качество сна → ниже recovery наутро.
- **Что меняю:** ровно ОДНА переменная — без добавленного сахара (сладкое, десерты, сладкие напитки)
  **после 18:00**. Тренировки, отбой, кофеин, бады — не трогаю. Только один активный эксперимент.
- **Baseline (до):** ⏳ **заполнить медианой за стабилизационную неделю** (recovery avg, эффективность
  сна). НЕ брать с плохого дня — иначе улучшение спутаем с регрессией к среднему. Отметить обычный
  недельный разброс recovery (±?), чтобы критерий был выше шума.
- **Срок:** 3 недели (до 04.07.2026).
- **Первичная метрика (одна):** **эффективность сна по Whoop, avg за период** (исход ближе всего к
  гипотезе). Вторичные (recovery avg, настроение) — только наблюдаем, вердикт не по ним.
- **Критерий успеха (пред-регистрация):** эффективность сна **+5 п.п. к baseline-медиане** и выше
  обычного недельного разброса. ⏳ уточнить порог после фиксации baseline.
- **Washout / реверс:** последние 4–5 дней вернуть вечерний сахар — проверить, что сон откатывается
  (без этого вывод остаётся корреляцией).
