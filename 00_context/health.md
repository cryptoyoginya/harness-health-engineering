# Контекст — домен «Здоровье»

> Immutable-ish контекст: что это, как устроено, где границы. Файл №3 в обязательном чтении (AGENTS.md).

## Что это

Личная база знаний о теле и психике + AI-оснастка, которая ведёт по слоям без коротких путей. Покрытие —
многомерное, в духе Blueprint Брайана Джонсона: **сон/восстановление, бады, нагрузка, виды активности,
питание, социализация, ментальное состояние**. Не приложение с кнопками — текст-первый интерфейс:
markdown-файлы + агент в терминале + MCP + локальный viewer.

## Роль Whoop (три слота сразу)

- **LSP (линтер организма):** утренний recovery — диагностика в реальном времени, подсветка «ошибки»
  до того, как она скомпилируется в перетренированность или выгорание.
- **MCP (read-tool по телу):** объективные данные — recovery %, HRV (`hrv_rmssd_milli`), пульс покоя,
  длительность/эффективность сна, strain. Тянутся автоматически через `scripts/whoop/sync.mjs`.
- **Генератор сигналов:** половина стадии Signal автоматизирована — физиология падает в daily-лог сама.

Whoop видит **только физиологию**. Ментальное (настроение, энергия, тревога, стресс, соцконтакт) —
субъективные сигналы, которые приносит человек. Самое ценное — на стыке: синтез связывает объективное
с субъективным.

## Измерения (что отслеживаем)

| Измерение | Источник | В логе |
|---|---|---|
| Сон + восстановление | Whoop (авто) | recovery, сон, HRV, strain, пульс покоя |
| Бады (стек) | реестр + рука | строка `бады:` (адхеренс ✓/пропуски) |
| Нагрузка | Whoop strain + рука | в `whoop:` и `активность:` |
| Виды активности | рука | `активность:` (тип + длительность) |
| Питание | рука | `питание:` (тайминг, кофе/алкоголь/поздняя еда) |
| Социализация | рука | `соц:` (да/нет + качество) |
| Ментальное | рука | `ментальное:` (настроение/энергия/тревога 1–5) |

Реестр стека — [`/03_wiki/health-supplements.md`](../03_wiki/health-supplements.md). Личные бейзлайны и
таксономия активностей — [`/03_wiki/health.md`](../03_wiki/health.md).

## ⚠️ Медицинская граница

Агент **не ставит диагнозы** и не интерпретирует симптомы как медицинские состояния. Метрики — прокси,
не клиника. Тревожный сигнал (боль, стойкое снижение настроения, непонятное с телом) → единственная
рекомендация: **врач/специалист**.

## Ритуалы (расписание, не tool-hooks)

- **Утро:** `pnpm whoop:sync` → recovery задаёт цвет дня (зелёный/жёлтый/красный плейбук). Решение
  принято заранее в `CLAUDE.md`, воля в моменте не нужна.
- **Вечер:** дополнить daily-лог ментальной строкой (~20 сек).
- **Воскресенье 18:00:** weekly-синтез (`skills/health-weekly-synthesis.md`).
- **Триггер:** HRV ниже личного бейзлайна 3+ дня → внеплановый разбор.
- **Gate:** перед тяжёлой тренировкой — recovery <50% → нет (правило `CLAUDE.md`, не git-hook).
